# 📊 Business Management Dashboard

A responsive business management web application built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Demo](https://YOUR-USERNAME.github.io/business-management-dashboard/)

## 📌 Project Overview

This project is designed as a small business management system that combines inventory, orders, customers, and sales analytics into a single dashboard.

## ✨ Features

### Dashboard

* Total revenue
* Total orders
* Total products
* Low-stock products
* Monthly sales overview
* Top-selling products
* Low-stock alerts

### Product Management

* Add products
* Edit products
* Delete products
* Search products
* Filter by category
* Track stock
* Calculate inventory value

### Order Management

* Create orders
* Automatically reduce inventory
* Search orders
* Filter by status
* Update order status
* Cancel orders
* Delete orders

### Customer Management

* Add customers
* Edit customers
* Delete customers
* Search customers
* Track order count
* Calculate customer spending

### Additional Features

* LocalStorage data persistence
* CSV order export
* Responsive design
* CRUD operations

## 📈 Business Logic

The application connects multiple business workflows.

For example, when a customer places an order:

1. The order is created.
2. The order total is calculated.
3. Product stock is automatically reduced.
4. Revenue is updated.
5. Customer spending is updated.
6. Dashboard statistics are refreshed.
